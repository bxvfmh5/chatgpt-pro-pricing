## 三档怎么选：先把 Ultrafast 的账算清楚

### Pro 100、Pro 200、Pro 500 分别适合谁

**Pro 100（$100，5 倍用量）** 适合每天都要用、但用量中等的重度用户。相比 Plus，它去掉了 5 小时窗口，包含 Pro 模型、Codex、deep research、图像生成、记忆和文件上传。第一档没有 Ultrafast。

**Pro 200（$200，10 倍用量）** 现在是中间档。对新订阅者来说，它的用量单价和 Pro 100 完全一样，多花的 100 美元买的是更高的上限，也就是更少撞限额。如果你最近一个月经常把额度用光然后干等重置，这一档有意义；如果 Pro 100 的额度对你绰绰有余，没必要往上跳。

**Pro 500（$500，25 倍用量）** 是独占功能档。个人订阅里只有它能用 Ultrafast，也只有它支持在 Codex 和 ChatGPT Work 里通过 Agents API 进行电脑操作。

### Ultrafast 值不值那 300 美元差价

Ultrafast 指的是 GPT-6 Astra Ultrafast，官方数据是最快可达标准模式的 8 倍速度，约每秒 300 个 token。Sam Altman 在上线当天的原话是：“Ultrafast 快到我再也不想回去了。”

但速度是要拿额度换的。Ultrafast 模式下，包含额度按 8 倍速率消耗（Fast 模式是 2.5 倍）。算一笔账：Pro 500 的 25 倍用量如果全程开着 Ultrafast，实际只够做大约 3 倍多 Plus 体量的 Astra 工作——比 Pro 100 标准速度下的总量还少。包含额度用完后再用购买的 credits 跑 Ultrafast，按 6 倍费率计。

所以判断标准很简单：Ultrafast 本质上是个延迟产品。如果你是盯着 agent 写代码、等待时间就是瓶颈的那种人，8 倍速度值回票价；如果你习惯把任务挂到半夜跑、早上再看结果，它基本是在烧钱。比较稳妥的用法是默认标准速度，只在真正坐在屏幕前等结果的交互任务里切过去。

## 用量用完了怎么办

Pro 的用量限制不会终止订阅，也不代表账号被限制，只是对应模型的额度用完了，等它重置或者换别的模型。ChatGPT 会显示重置时间。客服无法手动重置限额，这点官方写得很明白。

想继续用，可以买 credits：在 ChatGPT 的 Settings → Usage（Codex 里是 Usage & Billing）查看余额和购买。credits 适用于 Codex、ChatGPT Work、ChatGPT for Word / Excel / PowerPoint 这类符合条件的功能，并非所有模型和功能都能用 credits 续。

两个提醒：Fast 模式按 2.5 倍速率消耗额度；在 Pro 100 和 Pro 200 上，买再多 credits 也解锁不了 Ultrafast——它只对 Pro 500 开放。
